## Why this is not a certificate

This document is a **draft readiness assessment**. It has not been issued, it carries no
validity period, and it confers nothing. It exists so that the developer can see what would
have to be true before a commissioning certificate could be issued against milestone MS-10.

**It must not be presented to a buyer as a held certificate, and any answer that cites it as
evidence of commissioning is wrong.**
